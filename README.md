# Bảo Đạt Phiêu Lưu Ký (Bao Dat's Adventure)

Play in your browser: https://lephanbaodang.github.io/bao-dat-adventure-play/

A 2D platformer for kids: run, jump and stomp through a schoolyard, a classroom and the city at night,
then solve a math question to clear each stage.

**Controls:** Arrow keys move · C jumps · hold X to run · Space/Enter/Esc pauses · Enter starts the game

This repository only contains the published web build (made with Unity 6).
